# FrankenDuck print set

Source: <https://github.com/kissqy/Microduck-kissqy/tree/main/hardware/3d-print-frankenduck> (archive `Microduck-Print-FrankenDuck-20261015.rar`).

Only the file and folder names were changed, from Chinese to English. `NAME-MAP.txt` lists every original name next to the new one. The English names are my own best-effort translations. The models themselves are not edited.

The TPU soles (`stl-models/TPU-parts/*-sole-TPU.stl`) are saved in meters. Scale them by 1000 in your slicer (about 41 x 54 x 13 mm).
