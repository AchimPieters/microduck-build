# Building a micro-Duck

Notes, files and blog drafts for my build of a **Pollen Robotics Microduck** replica, using the [kissqy/Microduck-kissqy](https://github.com/kissqy/Microduck-kissqy) design (Feetech HD-1910 servos, Radxa ZERO 3W).

Website: <https://www.studiopieters.nl>

## The blog series

Parts 1 to 3 describe an earlier plan (the XGO-Duck). From Part 5 on, the build follows the kissqy design.

## What is in this repository

| Folder | Contents |
|---|---|
| `print-files/` | The FrankenDuck 3D print set (36 STL files and a 3MF plate layout) with English file names. `NAME-MAP.txt` lists the original Chinese names. |
| `notes/` | My research notes, build plan and order list (in Dutch). |
| `blog/` | Markdown drafts of Parts 1, 2 and 4. |
| `CLAUDE.md` | Goals, rules and status of the project, used as instructions for Claude Code. |
